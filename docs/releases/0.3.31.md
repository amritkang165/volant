## Changed

- **Install with Homebrew.** `brew install --cask mysticcoders/tap/volant` installs Volant, and each release updates the cask. The app still updates itself through Check for Updates. (#344, #345, #346)
- **Comparisons on usevolant.com.** New pages compare Volant with Raycast and with Alfred, including where each of them is ahead. (#343)

The app itself is unchanged from 0.3.30.

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
