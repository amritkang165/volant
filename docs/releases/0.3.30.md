## Changed

- **Volant now needs a Mac with Apple silicon.** Macs with Intel processors stay on 0.3.29 and aren't offered this update. (#338)
- **Volant is less than half the size.** The installed app is about 21 MB, down from 45 MB: it no longer carries an Intel copy of itself, and each of its helpers now includes only the code it uses. (#338, #339)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
