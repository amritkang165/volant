## New

- **Search only contacts, files or your clipboard.** Type `contacts` (or `people`), `files` or `clipboard`, then press Return or Tab to search just that source, the way commands work in Raycast. Type it in one go to get results right away: `contacts jane`, `files report`, `clipboard invoice`. The `@`, `/` and `clip` shortcuts still work as before, and Volant asks for Contacts access only when you first search for a name. (#360)

## Fixed

- **File search finds your files again.** In 0.3.33 and earlier, `/` and file results in search came back empty: macOS only gives a sandboxed app the Spotlight results it may read, which left out your own files. Volant's helper now runs the search by file name across your home folder and returns at most 8 matches; it receives only what you type and logs nothing. (#363)
- **File search shows what it's doing.** "Searching files…" appears while results load, and a search that finds nothing says so instead of showing an empty list. (#363)

Requires macOS 15 or later on Apple silicon. Dictation requires macOS 26.
